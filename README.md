# N23 Agent

Personal automation tool by Mahammed Hussain for his own YouTube channel (N23 GAMING).

## What this app does
- Finds viral videos on YouTube for research and trend analysis
- Uploads the owner's own videos and reels to his own YouTube channel
- Reads the owner's channel statistics (views, likes, subscribers, revenue)
